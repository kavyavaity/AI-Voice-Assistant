# AI Voice Assistant 🎙️🤖

An AI-powered Voice Assistant built using Python.

## Features

- Voice Recognition
- AI Chat using Gemini API
- Open Apps using Voice
- Close Apps using Voice
- Open Websites
- Weather Information
- Spotify Music Player
- Screenshot Capture
- Text-to-Speech Response

## Technologies Used

- Python
- Google Gemini API
- SpeechRecognition
- pyttsx3
- requests
- pyautogui
- psutil

## Installation

### Clone the repository

```bash
git clone <your-github-link>
```

### Go to project folder

```bash
cd AI-Voice-Assistant
```

### Install dependencies

```bash
pip install -r requirements.txt
```

## Environment Variables

Create a `.env` file and add:

```env
GEMINI_API_KEY=your_gemini_api_key
WEATHER_API_KEY=your_openweather_api_key
```

## Run the Project

```bash
python main.py
```

## Voice Commands

Examples:

- "Open YouTube"
- "Open Spotify"
- "Close Spotify"
- "What's the weather"
- "Take screenshot"
- "Play music"
